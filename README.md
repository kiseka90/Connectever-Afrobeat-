# Connectever Afrobeat

Welcome to Connectever Afrobeat!

Connectever Afrobeat is a music streaming platform designed to help listeners discover and enjoy Afrobeat music.

## Planned Features

* Stream music online.
* Discover Afrobeat artists and songs.
* Display website banner advertisements.
* Play audio advertisements between songs.
* Support mobile phones and computers.

## Music and Advertising

Music will be streamed with the necessary permissions or licences. Advertising features will be added as the platform develops.

## Project Status

The platform is under development.
